# 摩奇拉儿歌 · 本地离线播放器

通力时代 Mokila IP 授权儿歌 **432 首**（48 张专辑，总时长约 20.8 小时，1141 MB）。

这是一个**自包含的静态网站项目**：所有曲目数据内嵌在 `index.html` 中，所有音频都在 `摩奇拉儿歌/` 目录下，
**全部使用相对路径**，拷贝到任何位置都能直接使用，不需要服务器、不需要联网。

## 快速开始

**方式一：双击打开（最简单）**

双击 `index.html`，用 Chrome / Edge / Firefox 打开即可播放。

> 浏览器会因安全策略阻止 `file://` 页面加载本地音频的情况较少（Chrome 允许同目录相对路径音频），
> 若遇到静音或无法播放，请改用方式二。

**方式二：起一个本地静态服务器（推荐，兼容性最好）**

在本目录执行任一命令：

```bash
# Python（自带，无需安装依赖）
python -m http.server 8000

# Node.js
npx serve -l 8000 .
```

然后浏览器访问 <http://localhost:8000/>。

**方式三：Windows 一键脚本**

双击 `启动本地服务.bat`，会自动开服务并弹出浏览器。

## 播放器功能

- 歌名 / 专辑 / 歌手 **实时搜索**
- 左侧 **专辑分类**筛选
- 播放 / 暂停、上一首、下一首
- 进度条 **拖动跳转**、音量调节、静音
- 三态循环模式（列表循环 / 单曲循环 / 随机）
- **随机播放**按钮
- 键盘快捷键：`空格` 播放/暂停，`←/→` 上一首/下一首，`↑/↓` 音量，`M` 静音，`F` 全屏
- 正在播放的曲目有动画高亮

## 目录结构

```
mymusic/
├─ index.html            播放器主文件（双击即用，数据已内嵌）
├─ README.md             本说明
├─ 启动本地服务.bat        一键启动本地 HTTP 服务
├─ 摩奇拉儿歌.m3u          通用播放列表（可用 PotPlayer / VLC 等打开）
├─ 摩奇拉儿歌/             音频文件，按专辑分子目录（432 首）
└─ data/
   ├─ manifest.json      曲目元数据（歌名 / 歌手 / 专辑 / 网易云 ID / 文件大小）
   └─ durations.json     每首曲目时长（秒）
```

项目本身不需要任何脚本或依赖即可运行 —— 播放器是一个零依赖的单文件 HTML，曲目数据已全部内嵌其中。

## 数据说明

- `index.html` 内的 `const DATA = {...}` 包含全部 432 首的
  `歌名 / 歌手 / 专辑 / 相对路径 / 时长`，路径形如 `摩奇拉儿歌/<专辑>/<歌名>.mp3`。
- `data/manifest.json` 保留原始来源信息，含网易云音乐 ID，便于溯源。
- `data/durations.json` 为从 MP3 帧头解析出的精确时长。

## 注意事项

- 文件名含中文、日文、韩文及 `'` `&` `+` `《》` 等字符，均已验证在 `file://` 与 HTTP 下均可正常播放。
- 音频为 128kbps MP3，总体积约 1141 MB。
- 曲目版权归通力时代（Mokila）所有，仅供个人学习与家庭使用。
